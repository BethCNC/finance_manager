## 🎨 **Logo Sourcing Tips**

### **Best Sources for High-Quality Logos:**
1. **Official Brand Guidelines** - Most companies provide official logos
2. **Simple Icons** - Clean, simple versions work best
3. **PNG with Transparency** - Best for web use
4. **Consistent Sizing** - Aim for 64x64px or 128x128px
5. **High Contrast** - Works well on both light and dark backgrounds

### **Recommended Logo Sources:**
- **Brand Guidelines Pages** (e.g., `brand.amazon.com`, `brand.apple.com`)
- **Simple Icons** (`simpleicons.org`)
- **Feather Icons** (`feathericons.com`)
- **Heroicons** (`heroicons.com`)
- **Lucide Icons** (`lucide.dev`)

### **File Naming Convention:**

## 💡 **Pro Tips**

1. **Start with High Priority** - Focus on merchants that appear most frequently in your data
2. **Use Generic Fallbacks** - Create generic icons for categories when specific logos aren't available
3. **Consistent Style** - Try to use logos with similar visual styles (outline vs filled)
4. **Test Fallbacks** - Make sure your fallback system works when logos are missing
5. **Optimize File Sizes** - Keep logo files under 50KB for fast loading
